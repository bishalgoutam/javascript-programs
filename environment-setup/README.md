# JavaScript Environment Setup

This directory contains scripts and guides for setting up a JavaScript development environment.

## 📋 Environment Requirements

### Node.js Development
- **Node.js**: Version 18.0+ (LTS recommended)
- **npm**: Version 8.0+ (comes with Node.js)
- **Code Editor**: VS Code, WebStorm, or similar

### Browser Development
- **Modern Browser**: Chrome 90+, Firefox 88+, Safari 14+, Edge 88+
- **Developer Tools**: Built-in browser debugging tools

## 🛠️ Setup Scripts

### Node.js Environment
- `validate_node_environment.js` - Validates Node.js installation and environment
- `package_manager_setup.js` - Demonstrates npm package management
- `browser_environment_check.html` - Tests browser JavaScript capabilities

## 🚀 Quick Start

1. **Validate Node.js Environment:**
   ```bash
   node validate_node_environment.js
   ```

2. **Check Browser Environment:**
   Open `browser_environment_check.html` in your browser

3. **Test Package Management:**
   ```bash
   node package_manager_setup.js
   ```
