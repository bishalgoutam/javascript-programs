## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/bishalgoutam/javascript-programs.git
   cd javascript-programs
   ```

2. **Set up Node.js environment:**
   ```bash
   # Check Node.js installation
   node --version
   npm --version
   
   # Install dependencies (if package.json exists)
   npm install
   ```

3. **Run examples:**
   ```bash
   # For Node.js programs
   node fundamentals/variables-datatypes/01_variables_demo.js
   
   # For browser programs, open HTML files in a browser
   open fundamentals/dom-manipulation/index.html
   ```
