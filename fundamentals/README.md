# JavaScript Fundamentals

This directory contains comprehensive JavaScript fundamental concepts and programs.

## Structure

```
fundamentals/
├── variables-datatypes/    # Variables, data types, and type conversion
├── operators/              # All JavaScript operators and expressions
├── control-structures/     # Conditionals, loops, and control flow
└── functions/             # Functions, closures, and scope
```

## Learning Path

1. **Variables and Data Types** - Understanding how to store and work with data
2. **Operators** - Performing operations and comparisons
3. **Control Structures** - Making decisions and repeating actions
4. **Functions** - Creating reusable code blocks and understanding scope

## Prerequisites

- Basic understanding of programming concepts
- Text editor or IDE
- Node.js installed (for running .js files)
- Modern web browser (for browser-based examples)

## Getting Started

Each subdirectory contains:
- Working JavaScript programs
- Detailed README with explanations
- Practical examples and applications
- Code comments explaining concepts

Start with variables-datatypes and progress through each section in order.

## Running Programs

```bash
# Navigate to specific directory
cd variables-datatypes

# Run with Node.js
node 01_variables_demo.js

# Or open files in browser console
```
