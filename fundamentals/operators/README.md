# JavaScript Operators

This directory contains programs demonstrating all JavaScript operators.

## Programs

### 01_operators_demo.js
Comprehensive demonstration of JavaScript operators including:
- Arithmetic operators (+, -, *, /, %, **)
- Assignment operators (=, +=, -=, *=, /=, %=, **=)
- Comparison operators (==, ===, !=, !==, <, >, <=, >=)
- Logical operators (&&, ||, !)
- Bitwise operators (&, |, ^, ~, <<, >>)
- Special operators (ternary, typeof, instanceof, in)
- Operator precedence and practical examples

## Key Concepts

- **Arithmetic Operators**: Perform mathematical calculations
- **Assignment Operators**: Assign values to variables
- **Comparison Operators**: Compare values and return boolean
- **Logical Operators**: Combine boolean expressions
- **Bitwise Operators**: Operate on binary representations
- **Operator Precedence**: Order of operations in expressions
- **Short-circuit Evaluation**: Logical operators that stop early

## Running the Programs

```bash
# Run with Node.js
node 01_operators_demo.js

# Or open in browser console and paste the code
```
