# JavaScript Functions

This directory contains programs demonstrating JavaScript functions and advanced concepts.

## Programs

### 01_functions_demo.js
Comprehensive demonstration of JavaScript functions including:
- Function declarations and expressions
- Arrow functions with various syntaxes
- Higher-order functions (functions as parameters and return values)
- Closures and lexical scoping
- Function hoisting and scope behavior
- Practical examples and real-world applications

## Key Concepts

- **Function Declarations**: Hoisted, can be called before definition
- **Function Expressions**: Not hoisted, assigned to variables
- **Arrow Functions**: Concise syntax, lexical this binding
- **Higher-Order Functions**: Functions that operate on other functions
- **Closures**: Inner functions accessing outer function variables
- **Scope**: Function, block, and global scope
- **Parameters**: Default parameters, rest parameters, destructuring

## Running the Programs

```bash
# Run with Node.js
node 01_functions_demo.js

# Or open in browser console and paste the code
```
