# Control Structures

This directory contains programs demonstrating JavaScript control structures.

## Programs

### 01_conditionals_loops.js
Comprehensive demonstration of control structures including:
- Conditional statements (if, if-else, if-else if-else, nested if)
- Switch statements with multiple cases
- For loops (basic, for...in, for...of)
- While loops (while, do-while)
- Control flow statements (break, continue, labeled break)
- Practical examples and real-world applications

## Key Concepts

- **Conditional Statements**: Execute code based on conditions
- **Switch Statements**: Multi-way branching with case matching
- **For Loops**: Iterate with initialization, condition, and increment
- **for...in Loops**: Iterate over object properties
- **for...of Loops**: Iterate over iterable values
- **While Loops**: Repeat while condition is true
- **Control Flow**: break, continue, and labeled statements

## Running the Programs

```bash
# Run with Node.js
node 01_conditionals_loops.js

# Or open in browser console and paste the code
```
